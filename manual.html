一、这套工具做什么、不做什么

做的是：把抢券时你自己浪费掉的时间全部清掉——不用从微信翻链接、不用等页面加载、不用找按钮、不用看时间。

环节 手动操作 用这个工具
找到券的入口翻微信聊天 → 复制 → 切抖音 → 粘贴，约 8–15 秒桌面图标一点直达，1 秒
对准开抢时刻看手机时钟，误差 1–3 秒毫秒倒数 + 自动校时，误差 <100ms
到点反应盯着屏幕手动点，易错过零点声音 + 震动 + 自动跳转，提前 5 秒唤醒
息屏/来电打断锁屏后要重新解锁找页面屏幕常亮锁定，不中断
先说清楚：没有任何工具能保证抢到。
券是限量发放的。假设放 1000 张、同时 5 万人在抢，理论成功率就是 2%——任何声称「99% 必中」的软件，要么在骗钱，要么用外挂脚本赌你的账号被封。
这套工具做的是把你的操作延迟压到接近 0，让你站在理论上限上，剩下的交给网速和运气。

二、第一次使用（3 分钟）

  1. iPhone 用 Safari 扫码打开上面的网址。
  2. 点底部「分享」→「添加到主屏幕」→ 命名「抢购」→ 添加。
  3. 回到桌面点图标进入，页面里已经预置了你给的两个券（A 券、B 券）。
  4. 点卡片上的「设定开抢时间」，填主播说上架的时刻。务必精确到秒。
  5. 点一次页面任意位置（触发一次播放许可），之后到点才有声音。
顺手做三件事，速度快一倍：
① 设置 → 显示与亮度 → 自动锁定 → 永不
② 设置 → 辅助功能 → 触控 → 打开辅助触控，屏幕上多一个圆点，抢的时候用另一只手连点
③ 提前 10 分钟点一次「立即打开」，让抖音把券页面缓存好

三、抢购当时怎么操作

开抢前 5 分钟

  • 打开抢购助手 → 点焦点卡片 → 进入全屏倒数，屏幕上只剩数字。
  • 确认抖音已经登录、支付方式已开通免密（否则会在支付页卡住输密码）。
  • 把手机调成响铃（不是静音），音量拉满。

倒数 5 秒

  • 程序会自动尝试跳转抖音（可在「设置」里改提前量 0/3/5/8/10 秒）。
  • 如果没跳过去，到 0 秒立刻点「立即下单 ↗」。

进入抖音之后（关键）

  1. 直播间挂车：点右下角购物袋 → 找到「100元代金券」→ 点进去 → 立即购买 → 提交。
  2. 主播弹券：听口令，弹窗出来直接点「抢」，不要犹豫。
  3. 提交订单页不要改数量、不要选规格，直接提交。
抖音券有一个坑：直播间卖的券不一定在商品详情页，很多时候只在购物袋里或主播的弹窗里。
所以正确姿势是：提前进直播间待着，而不是等到点才从外部链接跳。

四、进阶：做成「一键直达」快捷指令

如果每次都要点两次太慢，可以把它压成桌面一个按钮：

  1. 打开 iPhone 自带「快捷指令」App → 右上角「＋」新建。
  2. 添加操作 → 搜索「打开 URL」→ 填入券链接：
    https://v.douyin.com/3VZZx97Qr2o/（A 券）
    https://v.douyin.com/3IaiJcYU2rQ/（B 券）
  3. 长按这个快捷指令 → 「添加到主屏幕」→ 命名「抢A券」。
  4. 以后桌面点一下就进券页面，完全跳过微信。

两个券就建两个快捷指令，放到桌面同一屏，抢哪个点哪个。

六、为什么不用「自动点击」外挂

你可能会看到网上卖「抖音秒抢脚本」，几百块一套。不推荐，原因很实在：

  • 要拿到下单接口，就得破解抖音的请求签名（a_bogus、X-Bogus），这依赖客户端里的密钥，属于逆向，违反平台协议；
  • 签名算法随版本几天一变，脚本活不过一周，你就得反复买「更新」；
  • 风控识别到异常请求，轻则限制购买，重则封号——为了省几十块赔上账号不值；
  • iPhone 上更没有合法途径让外部程序点 App 里的按钮，所谓「iOS 秒抢」基本都是骗局或要越狱。
这套工具完全走官方客户端：只做「提前把入口摆好 + 准时提醒 + 一键跳转」，下单动作永远由你在抖音里完成。所以它不会被判定异常，可以长期用。

七、常见问题

Q：倒数不准怎么办？

页面右上角会显示校时偏差。绿色（±300ms 内）正常；显示黄色或「校时失败」，去「设置 → 通用 → 日期与时间」打开「自动设置」。

Q：到点没有声音？

iOS 要求用户先交互一次才允许播放音频。进页面后随便点一下即可解锁；也确认侧边静音拨片没打开。

Q：跳转抖音失败？

先确认抖音已安装。部分系统会拦截自动跳转，这时点页面上的「立即打开」按钮（用户手势触发，不会被拦）。

Q：抢到之后呢？

券会进抖音「我 → 订单」或「卡券」。注意有效期，早鸟券通常限特定时段使用。

Q：数据存在哪？会不会丢？

全部存在你手机浏览器本地，不上传任何服务器。可在「设置 → 导出数据备份」存一份 JSON，换手机时导入。
